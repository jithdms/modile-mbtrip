## 확인 범위와 한계

식당 23곳·카페 23곳 모두 공개 매장 안내의 주소, 영업시간 게시, 방문 후기 또는 사업자 활동 자료를 확인했다. 폐업·장기휴업으로 확정할 근거가 발견된 후보는 없으므로 46곳을 유지한다. 이는 공개 영업정보가 존재한다는 뜻이며 46곳의 당일 실제 영업을 전화·현장으로 확정했다는 뜻은 아니다. 검색 수집일과 실제 게시일을 구분하며, '영업 전', 당일 마감, 정기휴무, '폐업신고' 버튼 자체를 폐업으로 해석하지 않는다. 실시간 상태나 영업시간 자동 필터를 새로 만들지 않았다.

## 코드 반영

- 기존 40곳의 비어 있던 address를 채우고 거북섬 추가 6곳의 층·호수를 보완했다.
- 추천 화면에 주소를 표시하며 지도 검색과 신규 추천 일정의 주소에도 같은 값을 사용한다. 기존 저장 일정은 일괄 변경하지 않는다.
