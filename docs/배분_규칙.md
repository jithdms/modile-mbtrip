# 일정 배분 규칙

`jpScore`는 0이 J, 50이 균형, 100이 P입니다. 여행 멤버들의 점수 차이(최고 점수 - 최저 점수)에 따라 하루 일정 중 확정/자유 시간의 목표 비율을 정합니다.

| 멤버 점수 차이 | 확정 일정 | 자유 일정 |
|---:|---:|---:|
| 0–15점 | 60% | 40% |
| 16–35점 | 40% | 60% |
| 36–100점 | 25% | 75% |

일정 생성 시 사용자가 필수로 지정한 블록을 먼저 그대로 고정합니다. 남은 시간에 우선순위가 높은 선택 확정 일정을 넣고, 나머지 빈 시간은 자유 블록으로 표시합니다. 선택 일정은 시간대와 겹치면 넣지 않으며, 필수 일정끼리 겹치면 생성하지 않고 오류를 반환합니다.

현재 친구 목록은 화면 작업을 확인하기 위한 기존 일정표 샘플 멤버입니다. Firestore의 친구 목록 연결과 실제 여행 ID 전달은 로그인·초대 화면이 구현된 뒤 연결해야 합니다. 진단 완료 시 익명 Firebase UID와 샘플 여행 ID로 `Member/{tripId}_{userId}` 문서에 `userId`, `tripId`, `jpScore`를 저장합니다. Firebase Console에서 Authentication의 Anonymous 로그인 방식을 켜야 하며, 실제 여행 생성 기능이 생기면 샘플 여행 ID를 실제 ID로 교체해야 합니다. `app/google-services.json`은 로컬 전용이며 Git에서 제외합니다.
