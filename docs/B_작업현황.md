# B 담당 현재 작업 현황

기준: 2026-11-18, 실제 AndroidStudioProjects/modile-mbtrip의 soyul. 이 문서가 현재 범위·결과의 기준이다. 과거 단계별 검증 문서는 당시 기록이다.

## 담당 기능

| 기능 | 구현·연결 상태 | 확인 내용 |
|---|---|---|
| J-P 진단·결과 | 구현 및 Firebase 저장 연결 | 10문항, 미응답 차단, 0=J/100=P, 결과·재진단, 저장 실패 처리 |
| 일정 배분 | 구현 및 일정 저장 연결 | 동행자 점수 비율, 기존 예약·투표·잠금·자유시간 메모 보존, 충돌·오래된 미리보기 차단 |
| 친구·동행자 | 현재 여행 동행자 범위로 구현 | trips/{tripId}/members 실시간 목록·검색·생성자 내보내기, 서버 접근 제한 |
| 시흥·거북섬 추천 | 식당 23곳·카페 23곳 | 지역·종류·체류시간·기존 장소 제외, 선택→미리보기→저장, 주소·지도·후기 연결 |

관광 8곳·체험 2곳은 담당 범위 정정에 따라 추천에서 제거했다. 다른 담당자의 관광 화면이나 기존 저장 일정은 삭제하지 않았다. 계정 전체 친구 기능이나 프로필 사진 업로드를 완료 범위로 포함하지 않는다.

## 이번 마감 변경

- 46곳 모두 주소를 명시하고 추천 화면, 지도 검색어, 새 추천 일정에 전달한다.
- 노을조개는 네이버 플레이스와 최근 인허가 기록 기준 거북섬로 110, 마리나베이101 2층 252호를 사용한다. 앞선 거북섬1로 4 안내는 정정한다.
- 조개포차·함돈의 근거 링크를 매장 상세 페이지로 보완했다.
- 네이버 블로그 버튼은 모바일 통합검색으로 이동하던 구형 where=blog 주소 대신, 실제 블로그 탭에서 확인한 ssc=tab.m_blog.all 주소를 사용한다.
- 현재 상태·남은 일·게시 안내 문서를 최신 기준으로 다시 정리했다.

## 검증 결과

- 전체 단위 테스트 97개 통과, 앱·테스트 APK 빌드 성공.
- 전체 화면·Firebase 실서버 검사 29개 통과. 이메일 가입·재로그인, 초대, 계정 전환·여행 복원, 진단·동행자·일정 저장, 동시 편집·내보낸 사용자 접근 차단 포함. 임시 데이터 cleanupErrors=[] 확인.
- 이후 블로그 URL 수정은 단위 97개 및 실제 외부 앱 실행 검사로 추가 검증했다. 실서버 데이터 처리 코드는 이 수정에서 바꾸지 않았다.
- 독립 AVD 2대 검사는 [최종 통합 검증](최종_통합_검증.md)에 기록한다.
- 링크 버튼의 앱 실행 검사와 실제 페이지 확인 범위도 위 문서에서 구분한다.

## 앱에서 확인하는 순서

로그인/가입 → 여행 생성 → J-P 진단 → 초대 코드 발급·동행자 참가 → 여행 동행자 보기 → 일정표·추천 보기 → 맛집·카페 추천 → 장소 선택 → 배분 미리보기 → 일정에 반영.

이메일 로그인·초대·계정별 여행 복원은 실제 저장소 경로에 연결했다. 일부 팀원 프로필·후기·숙소·교통 화면의 예시 데이터나 세션 전용 입력을 서버 영구 저장 완료로 표시하지 않는다.

## 유지하는 선택과 후속 확인

- 지도·후기는 별도 키·결제 없이 외부 서비스에서 확인한다. 실시간 평점·자동 영업시간·실제 이동시간 계산을 이번 완료 조건에 추가하지 않는다.
- 46곳의 공개 영업 안내를 재확인했으며 폐업으로 확정할 근거는 발견하지 못했다. 당일 실제 영업을 전화·현장으로 확정한 것은 아니다.
- 사용자가 선택한 가상 기기 우선 검증 이후 실제 휴대전화 2대 사용성 확인은 후속 범위다.
